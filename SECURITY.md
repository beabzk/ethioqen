# Security Policy

## Supported versions

Only the latest release line is supported. Older releases, including
every version before the current minor, receive no security fixes.

## Reporting a vulnerability

**Do not open a public issue.** Report privately via a
[GitHub private vulnerability report](https://github.com/beabzk/ethioqen/security/advisories/new)
against this repository.

Include:

- Affected version(s) and Python version / OS.
- A minimal reproducer (script or test case).
- Impact assessment if known (wrong conversion results, crash, hang).

You will receive an acknowledgement, and we will coordinate a fix and a
release before any public disclosure. Dependent on severity, the fix ships
as a patch release with a CHANGELOG entry crediting the reporter (unless
anonymity is requested).
